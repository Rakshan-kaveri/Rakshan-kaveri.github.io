# Rakshan Kumar — Personal Profile

A clean, responsive personal profile website for Rakshan Kumar, a 3rd-year B.Tech Information Technology student at MIT Manipal.

## Tech
- HTML
- CSS
- JavaScript

## Local development
From the project folder, open `index.html` in a browser or run a small local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages deployment
This project is prepared for GitHub Pages hosting.

1. Push the repository to GitHub.
2. In GitHub, open the repository.
3. Go to Settings → Pages.
4. Set Source to `Deploy from a branch`.
5. Set Branch to `main` and Folder to `/`.
6. Save.

Live URL:
https://Rakshan-kaveri.github.io/

## Replace the profile photo
Place the real profile image at:

`assets/profile.jpg`

The page includes a graceful placeholder if the image is missing.
