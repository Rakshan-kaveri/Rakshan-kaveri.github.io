FEATURED PROJECTS

Private Share

End-to-end encrypted calls, screen sharing and file transfer in the browser

Live demo ↗ Source ↗

Voice and video calls, screen sharing with sound, and file transfer up to 1 GB between two browsers on phone or PC. The server only signs people in and relays signalling; everything else travels device to device.

  • Own encryption layer on top of WebRTC: ECDSA P-256 device keys, fresh ECDH + HKDF per call, AES-256-GCM per file with signed SHA-256 manifests
  • 12-digit safety code so two people can verify nobody is in the middle
  • Zero runtime dependencies on the server; 27 end-to-end Playwright tests across desktop and phone browsers
  • Hardened Docker deployment with a coturn TURN relay, on Google Cloud behind Cloudflare Tunnel
JavaScript Node.js WebRTC Web Crypto API WebSockets Docker Playwright

SkyCast

Live weather maps, alerts and daily reports by email and SMS

Live demo ↗ Source ↗

A full-stack weather platform with an interactive map of live satellite, radar, wind and cyclone layers, personal forecasts, saved places, and scheduled daily reports, including an SMS-only farmer mode in English, Kannada and Hindi.

  • Background worker for scheduled reports, hourly alert rules and 30-minute severe-weather checks (IMD rainfall thresholds, live cyclone feed)
  • Signed delivery webhooks record whether every email and SMS was delivered, opened or bounced
  • Admin control room with users, last sign-in location, subscriptions, delivery log and one-click resend
  • Google OAuth sign-in, PostgreSQL via Prisma, installable PWA with offline forecast
